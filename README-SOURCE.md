# 豆作间对应源码

修改：Codex，2026-10-25。AGPL-3.0。保留 Zippland 与贡献者的原版权及声明，详见 LICENSE、THIRD-PARTY-NOTICES.md、docs/UPSTREAM-CHANGES.md。

需要 Node.js 22.18+，无第三方运行依赖，无安装步骤。在本目录运行：

```sh
node scripts/prepare-upstream.mjs
npm test
npm run build
npm start
```

打开终端输出的 127.0.0.1 本地地址；Ctrl+C 关闭。npm run verify 会启动临时服务、检查资源、关闭服务。默认端口随机，可通过 `npm start -- --port 5173` 指定。

此压缩包包括实际客户端的 HTML/CSS/JS、图片素材、参考色板、Worker、转换/编辑核心原始 TypeScript、修改与构建脚本、测试和完整许可。原上游完整应用并未被链接执行；只移植两个工具模块和色板。所需上游源文件已经包含，构建不需要访问 GitHub、密钥或联网下载依赖。内部研究笔记和用户图片不包含在此包中。

图片在浏览器内处理，无服务器上传接口；当前编辑只保留在当前标签页，刷新会重置。MARD 为上游参考版，未进行实体色卡校准；指南为厂商资料摘要，未完成实物烫豆测试。AI 插画由 Image Gen 生成；几何图案由 Codex 编写。PNG 是带图号网格的参考图，不提供 1:1 拼板打印校准。

当前v0.2.0：图案宽高1–128格，板型预设/自定义与图案独立，四边坐标、数格线、板缝提示、36px/格清晰模式和平移、完整色板补色、原图参考、连续笔画撤销；PNG包含完整色号与用量。板型只用于布局分区，不保证跨型号实物拼接，板分区不等于已生成独立分板文件。

最新v0.2.1覆盖此前缩小隐藏色号的设计：滚轮直接连续缩放，范围1%–3200%，鼠标锚点与拖动平移，任意百分比输入。每个实际放豆格始终绘制原色号，空格无色号。缩放重用既有栅格，不因每次滚轮重画整张图；图案本身仍为单边1–128格，这次没有扩充图案上限或增加独立分板文件。

最新v0.3.0：现成图纸独立列表与详情，分类/关键词/尺寸/色数筛选及用豆排序；数据接入见docs/CATALOG.md。换板默认自动适配原图比例并生成，可关闭以保留多板图纸。屏幕读图改为SVG矢量文字，覆盖v0.2.1固定栅格放大方案；PNG仍为独立全图导出。当前收录4张原创示例，尚无新第三方图纸。

最新v0.3.1：全站用户文案审校，导出内容同步简化；移除无实际进度含义的装饰性准备状态。功能与数据范围沿用v0.3.0，原作者署名及完整许可保留。

最新v0.3.2：导出文件包含https://douzuojian.com/访问引导；示例对外署名统一为豆作间原创几何示例。运行npm run build后可运行npm run release，发布目录为releases/0.3.2。实际部署需要托管账户授权，当前打包不代表已上线。
