隐私政策

更新日期：2026年11月1日。

图片处理

你选择的图片不上传服务器，图片转换与图纸编辑在浏览器本地完成。导出的PNG和CSV由浏览器保存到你的设备。

本机草稿数据与隐私

保存位置与内容

草稿使用浏览器的IndexedDB本地存储，保存在当前设备、当前浏览器对豆作间这个网站分配的空间中，不是上传到站方账号或服务器的云端文件。草稿功能不需要注册或登录，也不使用Cookie来保存图纸。

保存的内容包括：图纸名称、尺寸、每个格子的位置与色号、所用品牌和参考色板版本、可用颜色、豆板规格、必要的生成与导出参数、来源说明、草稿标识、修订号和最近保存时间。上传图片生成图纸时，图纸名称默认可能来自文件名。原始上传图片和撤销/重做历史不会写入草稿。

数据传输与访问

本机草稿功能不会主动将草稿名称、图纸矩阵或这些参数发送给豆作间服务器、广告平台或统计服务。站方没有接收这些草稿的后台，也不通过本机草稿建立用户账号或跨设备同步。网站访问和广告仍涉及第三方服务，相关Cookie、日志和保留方式见下文。

使用同一设备、同一浏览器用户配置的人，可能在本站看到这个浏览器中保存的草稿。共用设备时，可在使用结束后清除自己的草稿。

保存期限和删除

本站没有为草稿设置自动到期日。数据通常保留到你主动清除，或浏览器、系统清理本站存储；无痕模式、空间不足或浏览器设置也可能使保存失败或数据被回收。请以工坊实际显示的保存状态为准，不把它当作永久备份。

在工坊选择草稿，点“清除所选草稿”并确认，可删除这一份本机数据。此操作不修改图库，不删除其他草稿，也不会清除当前画面；继续修改时会另存成新草稿。你也可以通过浏览器设置清理本站全部数据，但这会一并移除该浏览器保存的本站草稿。

换设备、换浏览器、换浏览器用户配置或网站地址，不会自动带走草稿。站方没有备份副本，无法远程恢复已清除的本机稿子；设备上的导出文件由你自行管理。查看保存、恢复和清除步骤。

Cookie 与广告

本站使用 Cookie 及 Google AdSense 广告。Google 及其合作伙伴可能使用 Cookie、设备标识和访问记录，根据你此前访问本站或其他网站的情况投放广告，并衡量广告效果。实际投放和数据处理由广告服务商负责。

你可以在 Google 广告设置中关闭个性化广告，也可以通过浏览器设置清除或限制 Cookie。限制 Cookie 不影响本地图片转图纸功能。详情见 Google 如何使用合作网站数据及 Google Cookie 政策。

分析工具与保存期限

本站目前未接入 Google Analytics、百度统计或其他独立访客分析脚本，也不建立访客分析数据库，因此本站不保存此类分析数据。广告展示、点击和收益统计由 Google AdSense 提供；本站无法将其关联到你在浏览器内处理的图片。

网站由 GitHub Pages 托管。GitHub 会出于安全目的记录和保存访问者的 IP 地址。Google 广告数据和 Cookie、GitHub 安全日志的保存期限由各服务商按用途和其隐私政策确定，本站无法指定统一天数。可查看 Google 数据保留说明及 GitHub 隐私声明。本机草稿保留到你主动清除或浏览器清理本站数据；设备上的下载文件由你自行管理。

主动提交的反馈

反馈通过 GitHub Issues 提交。你主动提供的文字、截图和账号信息由 GitHub 按其规则保存，且公开可见。请勿上传私密资料。需要更正或处理本站内容，可通过联系页提交。
